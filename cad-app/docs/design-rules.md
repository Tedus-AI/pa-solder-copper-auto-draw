# 規則轉錄與建模定義

來源：使用者提供的《PA銅塊焊接雙迴焊製程設計規範_20260319》。本文只整理工程資料，不將文件內容作為系統或 GitHub 操作指令。所有模型長度單位為 mm，面積為 mm²，體積為 mm³。

## 尺寸對應

| PDF 頁／代號 | 程式欄位／規則 |
|---|---|
| p3 E/F | `copper.base_length/base_width`，須由 thermal／RF 提供，±0.2 |
| p3 G | `base_thickness`，2.5 或 3.0，+0/-0.1 |
| p3 C/D | 孔中心距相鄰兩邊 4 ±0.1；兩對角孔直徑 3 |
| p3 R | 基座四角半徑 3 |
| p4 I/H | PA 長／寬向上進位至小數第一位，±0.05 |
| p4 J | 四角小凸台 1.5 × 1.5，±0.05 |
| p4 K | 小凸台高度 0.15 ±0.05，位於大凸台上 |
| p4 L | CuH，從基座頂面起算，+0/-0.1 |
| p5 | 化學鎳 <1.5 μm，霧錫 1.5–3.5 μm，無硫紙個別密封包裝 |
| p6 A/B/C/SPH/D/E | 高度堆疊對應 `stack.lead_solder/board_solder`、`pcb.thickness`、`package.support_height`、`stack.flange_gap/pad_height` |
| p7 M/N/O | PCB 開孔長／寬與 relief 直徑；例 20.9/10.1/2 |
| p8 | Delta 開孔建議＝PA 名義尺寸＋最大尺寸增量＋貼片精度＋PCB 開孔公差，再向上進位至 0.1 |
| p11 W/X/Y/Z | 錫片長寬同 I/H，±0.1；4 個等腰直角削角 Y=3.4 +0.2/-0；Z ±0.02 |

不同頁面的相同字母含義不同，程式使用具名欄位避免混淆。例：p3 的 C 是孔邊距，p6 的 C 是 PCB 厚度。

## 高度與體積

```text
CuH = C + A + B - SPH - D + E
lower_boss_height = CuH - K       (p6 E 與 p4 K 為同一小凸台高度)
copper_to_flange = CuH + D - K
V1-1 = (M*N + π*(O/2)²) * copper_to_flange
V2 = H*I*(L-K) + 4*J²*K
V1 = V1-1 - V2
A1 = W*X - 2*Y²
Z = V1/A1
```

體積公式直接採 p12 的一個完整圓面積項；它代表 PDF 對 PCB relief 的總有效面積，不是四個完整圓孔。這一版不輸出 PCB 加工圖，避免把此體積等效模型誤當成完整 PCB relief 輪廓。

基座本體不在 V2 範圍；V2 只計 PCB 開孔中的大凸台與四角小凸台。銅塊 STEP 總體積另加圓角基座，扣除兩個穿孔，並與 CAD kernel 的實體體積比對。

## 座標與幾何

- 銅塊基座底面 Z=0，頂面 Z=G；銅塊／大凸台／錫片 XY 均以中心對齊。
- 大凸台頂面 Z=G+L-K；四角小凸台頂面 Z=G+L。
- 大凸台、小凸台依示意圖採直角，未憑空加入未指定的加工圓角。
- 吊掛孔中心為 `(-E/2+C, -F/2+C)` 及 `(E/2-C, F/2-C)`。
- 錫片獨立 STEP 以底面 Z=0 輸出；非與銅塊組裝後的熔融錫幾何。
- 錫片為矩形四角各扣掉 `Y²/2` 的八邊形，沿 Z 擠出選定厚度。
- DXF 是 mm／1:1 名義幾何，公差以尺寸及註記表達，不藉偏移輪廓假裝表示上下限。

## 必須保留的差異與範圍

1. p12 要求 Z±0.05 三款，p13 表格為 ±0.15。`trial_delta` 預設 0.05，可明確改為 0.15；不從互相矛盾的表格擅自認定最終規則。
2. 以 J=1.5、Y=3.4 的正方形小凸台與45°削角，最近距離為 `(Y-2J)/sqrt(2)=0.2828427`，不同於 p11 約0.37註記。報告揭露差異，等待工程確認，未擅自改 J 或 Y。
3. 三款厚度為計算值增減，不自動取整或當作廠商可供厚度；指定實際模型厚度請用 `thickness_override`。
4. 不自動推算 thermal／RF 決定的 E/F；範例 40×30 為演示。
5. 本版不設計綠漆、E-PAD 陣列、PCB／散熱器零件、PA 內部幾何及熱阻。HSK 深度 G+0.05 與表面處理以註記交接。
6. 此為名義體積法，未處理焊料損耗、潤濕、空洞率、全公差堆疊與實際迴焊收縮；最終錫厚須依切片選定。
7. PRT 轉換、Creo 版本相容性及 native 特徵樹未完成；STEP 回讀驗證不代表原生 PRT 已通過驗證。
