# 尺寸工作區與 Layout 輸出

桌面以 24 吋常見 Full HD 螢幕為目標，並以 1920×900 的實際瀏覽器 viewport 驗證：設定分組並排、縮小頁首、重要尺寸與出圖操作同畫面可見，預設無需頁面或尺寸面板捲動。較小視窗只在必要的面板內捲動，手機維持可上下操作的版面。

點選任一數值欄位會切換到對應的銅塊／錫片／參考組裝／Layout 視圖，顯示真實尺寸線、延伸線、端點與數值，並以呼吸動畫定位。放置精度、公差與試片差值會以增量示意標註，避免誤當成目前零件尺寸。啟用作業系統減少動態效果時，標記改為穩定高亮。

輸入變更後使用輕量3D示意即時更新；3D出圖下載仍須重新建立並通過 OpenCascade 的實體／體積／STEP回讀驗證。獨立 Layout DXF 由目前有效參數直接生成。無效輸入會停用相應下載，並明示保留上次有效參考。

## 顯示與視角

銅塊、錫片、PCB 與 PA 均可獨立勾選顯示。隱藏會同時移除面及邊線，不改動出圖零件或下載內容。點選尺寸時自動顯示該尺寸需要的元件。右上角六面視角控制集中俯／仰／前／後／左／右；等角可還原斜視，拖曳後取消固定面選取。

## PA 與開窗尺寸關聯

PA 製造計算只有長、寬、尺寸公差及 SPH 四個輸入。「PA 尺寸公差 ±」即原欄位 `max_tolerance`，最大尺寸＝標稱＋公差，不重複加兩次。聚焦公差時，PA 最大外框以虛線表示。

- Delta：開窗原值＝最大 PA＋貼片放置精度＋PCB 開窗公差。
- Ampleon：最後一項改為 PCB 開窗公差÷2。
- M/N 為原值向上取到 0.1 mm；預設自動連動。取消「自動連動 M/N」可輸入既有開窗；手動值不足規則建議時顯示提醒，若小於銅塊凸台則拒絕出圖。
- 銅塊凸台 I/H＝PA **標稱**長／寬向上取到 0.1 mm；錫片長寬同 I/H。
- CuH＝C＋A＋B−SPH−D＋K；HSK 深度＝G＋0.05 mm。開窗及高度堆疊持續連動體積扣除錫厚，Layout U 同步開窗。
- 銅塊基座 E/F 仍依 thermal／RF 輸入。

範例：20.57×9.78、公差±0.127、貼片精度0.066、開窗公差0.1，Delta 原值20.863×10.073，向上取為20.9×10.1 mm。

參數檔新增 `pcb.opening_mode: auto | manual` 與 `pcb.opening_rule: delta | ampleon`。舊檔含 M/N 而沒有模式時，視為手動，保留原開窗。瀏覽器 YAML 可直接交給 Python CLI，兩側使用相同公式。

## PCB／PA 參考

- PCB 為銅塊外形周邊的局部板件，包含開孔／側向 relief；板厚為輸入的 C。
- PCB底面＝銅塊基座頂面＋B；PCB頂面再加 C。
- PA flange 位置由 CuH+D-K 計算；引腳底面＝flange位置＋SPH，與 PCB頂面保持 A。
- PA 依使用者所附 H-37248KC-6/2 圖比例繪製圓角金屬 flange、削角 casing／頂蓋與六支針腳（上側四支、下側兩支）。長寬依 PA 輸入縮放，高度依 SPH 縮放；引腳底面嚴格使用 SPH。其他厚度與針腳皆為示意，不能當成完整封裝設計；未新增影響製造的封裝輸入。
- 「分解」只影響視圖；點選尺寸時會回到真實裝配位置。
- STEP／STL 僅包含 `copper`、`preform`。PCB與PA從未傳入出圖CAD worker，也不會建立可供匯出的零件。

## 原始規範第9頁

| 代號 | 預設 | 用途 |
|---|---:|---|
| R | 1 mm | 依示意解讀為銅塊外邊之外的綠漆框帶 |
| S | 1.5 mm | E-PAD 名義正方形邊長 |
| T | 0.3 mm | E-PAD 之間的綠漆筋寬；格距為 S+T |
| U | 同 PCB 開窗 | 陣列與綠漆避開的PCB開孔輪廓 |
| V | Ø4 mm | E-PAD 避開的定位孔直徑範圍 |

格點以 PCB 開窗中心（0,0）對稱往 X/Y 排列，依銅塊圓角外形裁切邊界格。固定格距下，若某組 E/F 尺寸的邊緣剛好落於綠漆筋，會留下邊緣綠漆；實際餘量記錄於 report.json，需與 Layout 確認收邊，工具不擅自放大名義 E-PAD 或改動 RF 決定的 E/F。

依第9頁圖示，V用於排除 E-PAD，真實定位孔D至V之間保留綠漆環。R與V的這些圖示解讀會寫入 DXF 註記與JSON報告，便於工程交接確認。

PCB輪廓依第7／9頁四個側向半圓示意。第12頁錫厚公式的等效 πr² 面積項維持原公式，並不以參考模型的開孔面積取代，差異會揭露於圖檔註記。

## Layout DXF 圖層與正負片

| 圖層 | 意義 |
|---|---|
| `SOLDER_MASK` | 實際綠漆覆蓋區；封閉輪廓及帶內孔的 SOLID HATCH |
| `EPAD_OPENING` | 裸露 E-PAD／綠漆開窗；封閉輪廓與 SOLID HATCH |
| `MASK_BOUNDARY` | 包含R框帶的外界線 |
| `COPPER_BOUNDARY` | 銅塊外形參考 |
| `PCB_CUTOUT` | U開孔參考 |
| `HOLE_CLEARANCE` | V避讓圓參考 |
| `MOUNT_HOLE` | 實際D定位孔參考 |
| `NOTES` | mm／1:1、尺寸、圖層極性與假設 |

曲線的布林裁切採最大弦差0.001mm，3D示意與DXF共用同一份輪廓。Layout DXF 可單獨下載，完整ZIP也包含 `layout_solder_mask.dxf`。這是給Layout的綠漆/E-PAD幾何，不是完整PCB製造檔。

## 驗證

Node 測試另驗證 Delta／Ampleon 原值與進位、四個 PA 輸入連動、手動／舊檔保留、六面方向及 PA 示意引腳平面。瀏覽器驗證四種元件顯示開關、六面按鈕、開窗自動／手動與實際連動後的 STEP／ZIP。

Node測試驗證圖層、陣列、孔位避讓、面積分割、不改動銅塊/錫片體積，以及每個尺寸線長度與參數值一致。瀏覽器測試驗證桌面不捲動、真實呼吸畫面變化、尺寸與視圖連動、獨立Layout下載，以及ZIP僅含兩個製造零件的STEP/STL。另以 Python CadQuery／ezdxf 對實際下載檔進行獨立讀檔檢查。
