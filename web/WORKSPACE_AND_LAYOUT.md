# PA 銅塊尺寸工作區與出圖

[線上工具](https://tedus-ai.github.io/pa-solder-copper-auto-draw/) 是自含 HTML／JavaScript；Three.js 預覽、OpenCascade WebAssembly 製造模型與 GitHub Pages 部署。24吋常見1920×900／1080工作區中，設定區約605 px、3D區約佔67%寬；上下區塊等寬卡片、中間銅塊橫跨兩欄並整合基座與凸台，統一尺寸／公差欄；短桌面22 px列高，較高桌面25 px，主要設定不需捲動。移除上方指標列，公差開關集中至設定標題列，以增加畫布與設定區空間。1366×768仍維持左右並排，短畫面只在設定區必要時捲動；錫片／Layout預設展開，也可自行收合；手機使用單欄。

## 彩色 CAD 與標註

銅塊基座、中凸台、四角小凸台分成三種銅色，含實際出圖模型的網格；深色輪廓、棚光反射與接觸陰影讓俯視仍能看清凸台邊界。PA為銅色底座、單一深色封裝本體及六支示意金色針腳，沒有獨立的灰色頂蓋。參考 [anatomy 的明暗／厚度原則](https://github.com/wheresryan22/anatomy/blob/main/SKILL.md)，保留真正的彩色CAD與工程標註。

32個設計尺寸（Typ.）均有對應的實際尺寸端點。點選設計尺寸（Typ.）切換正投影判讀面；六面與等角仍可自由旋轉；選用六面時「正投影」亮起，等角按鈕與其互斥。尺寸文字固定深色，依實際字寬放在模型外側；一般尺寸水平，四角半徑文字沿外側斜引線排列，只有圓弧端點的光圈呼吸。數值統一為 `PA(L) = 20.57 ±0.127 mm` 等工程格式，重複特徵加數量：四角半徑 `4-R = 3.00 mm`、預設兩孔 `2-⌀D = 3.00 mm`（數量依所選角位變更），J/K/Y各4處，O4處、V依吊掛孔數量。這些特徵至少顯示兩位小數，仍保留更精細的輸入，例如3.005不會被改成3.00；尾零不代表另行指定製造公差。DXF同樣使用數量、代號／名稱、等號、數值及單位。小間距採外置箭頭。半徑選擇尚未被孔切除的圓弧，採就近的外側斜直線及單箭頭，不再畫穿過本體的圓心線；直徑使用實際直徑線與兩軸點劃中心線。

聚焦PA長／寬的公差欄時，只顯示最大外框虛線及外側公差文字，不另畫 ± 微小線段。SPH下端是PA金屬底座底面，上端是PIN底面，側視基準與示意模型一致。上方尺寸列獨立於模型區；極端放大無空白時保留尺寸列，可按「定位視角」還原。

銅塊、錫片、PCB、PA、E-PAD設計皆可獨立切換；隱藏或分解不影響製造圖檔。PCB為只有PA開窗／角部避空的局部板，不複製銅塊的吊掛孔；所選孔位仍保留於銅塊及Layout設計。E-PAD切換控制參考組裝／Layout的綠漆與開窗示意，不加入3D製造輸出。PA自身形狀及針腳為示意。STEP只有銅塊、錫片及兩者的組合；Layout、PCB、PA 不輸出 3D。


## 專案與 PA 型號

專案名稱與PA型號並排，支援中文及單行文字；專案名稱必填，PA型號可留空。Typ.表示未加上下公差的設計尺寸，不是實測平均值。銅塊基座、中凸台、四角小凸台整合於同一銅塊設定區；L標示為「中凸台總高L」。

專案保存完整尺寸、公差、專案名稱、專案ID、PA品牌、PA型號與銅塊／錫片料號，支援重新載入、更新、另存與刪除。工作副本在project-db.js：一律寫入瀏覽器快取；在「設定」選擇本機資料庫檔（local-file-db.js，File System Access API，可放共用磁碟）後同時寫入該檔，檔案被他人修改時停止寫入不覆蓋；備份資料夾每日一份、保留30份。開啟SharePoint雙存檔（sp-sync.js，沿用Thermal-Test-Report-Builder的設計）後，專案逐一存成Thermal-Spec-DB／文件／PA_Copper_CAD/Database/projects/<id>.json，以eTag避免覆蓋同事的修改（衝突時另存「衝突副本」），每日備份至PA_Copper_CAD/Backup保留2份。專案名稱可從AI-Thermal工具的ToolDatabase/thermal_db.json專案清單下拉選擇，本工具只讀不寫。CAD檔名代碼design.name與人可讀的project.name／project.pa_model分開，保持原生Creo檔名規則與舊參數檔相容。

## 公差來源與鎖定

每個尺寸旁有正、負偏差，輸入非負量。預設鎖定，按「解鎖公差」可修改。來源標記可查看文件頁碼；原文件沒有公差的欄位顯示「—／未指定」，分析暫按0，而非宣稱製造公差為零。手動值會標示來源變更。

| 尺寸 | 原文件公差 | 來源 |
|---|---|---|
| PA長、寬 | ±0.127 | 第8頁明載上限 +0.127；下偏差沿用雙向公差設定，可解鎖修改 |
| 基座E/F | ±0.2 | 第3頁 |
| 基座G | +0/−0.1 | 第3頁 |
| 孔中心距邊C | ±0.1 | 第3頁 |
| 中凸台I/H | ±0.05 | 第4頁 |
| 中凸台總高L | +0/−0.1 | 第4頁 |
| 四角小凸台J/K | ±0.05 | 第4頁 |
| PCB開窗M/N | ±0.1 | 第7頁 |
| 錫片W/X | ±0.1 | 第11頁 |
| 錫片削角Y | +0.2/−0 | 第11頁 |
| 錫片厚度Z | ±0.02 | 第11頁 |

SPH、PCB板厚、A/B/D間距、基座圓角R、孔徑D/O、Layout R/S/T/V及新增凸台位置公差均未指定。HSK（散熱器）須在銅塊的相對位置加工凹槽，槽深設計值為銅塊基座厚度G+0.05 mm；HSK槽深加工公差±0.05 mm，見第3頁。G=3 mm時，槽深設計值3.05 mm，允許深度3.00～3.10 mm。試片增減量依目前需求固定為±0.15 mm；與Z製造公差±0.02分開設定。

公差存在 `design.tolerances['group.field'] = {minus,plus}`。PA長寬／PCB開窗可有不同公差。舊檔的 `package.max_tolerance`、`pcb.opening_tolerance`會轉入新欄位；舊檔含M/N但無模式時保留手動開窗。

## 自動計算與圈圈問號

自動值旁的圈圈「?」可用滑鼠移入、鍵盤聚焦或手機點選，查看公式、目前代入值與結果。涵蓋M/N、I/H、L、W/X、PA最大尺寸、HSK深度、凸台下段高、錫厚／體積／面積、試片及間隙極值。手動模式的對應自動提示會隱藏；浮動說明不被尺寸面板裁切。

- I/H：PA標稱長寬向上取到0.1 mm；預設自動，取消跟隨可修改設計長寬（Typ.）。
- L：依**第6頁** `L = PCB厚度C + A + B − SPH − D + K`，固定自動計算，不能手填覆寫。A/B/D使用0.1／0.1／0.3 mm建議定值，SPH從PA帶入，高度區可調PCB厚度C與小凸台K。
- 中凸台本體高度＝L−K；四角J×J小凸台再向上拉K，所以總高仍是L，沒有把K重複加兩次。
- W/X跟隨I/H設計尺寸（Typ.），但錫片±0.1的公差與銅塊±0.05各自獨立。
- M/N：最大PA＋固定製程能力0.066＋PCB各軸下偏差（Delta）；Ampleon最後一項除2，再向上取0.1 mm。下偏差用來補償開窗加工縮小，對稱公差時與原PPT相同。0.066不再提供獨立可填欄位，也不作為尺寸公差。

## 錫厚圖解與 Excel 對照

點選左側「錫片設計」內的「錫厚圖解／計算表」按鈕，可開啟以目前尺寸代入的圖解。剖面可切換容腔V₁₋₁、銅凸台V₂及錫料V₁；錫片俯視圖顯示四角削角，並逐步列出h=L+D−K、Aₒ（四個外側避空半圓聯集面積）、V₁₋₁=(M×N+Aₒ)×h、V₁=V₁₋₁−V₂、A₁=W×X−2Y²及Z=V₁/A₁。與PDF第13頁Excel的差異只在Aₒ：原式只計一個整圓π(O/2)²。剖面水平、垂直使用相同比例，可等比放大。右側等角3D採同一組實際尺寸；體積按鈕同步切換兩圖，選中體積保持實體並明暗呼吸，其餘零件半透明。

圖解預設佔滿瀏覽器視窗，依1366×768、1920×900及2560×1440等實際可用解析度排版。右側約1/4整合尺寸列表及獨立定位3D；數值直接附單位，排除左側已說明的體積／面積／計算Z。定位列表不列試片增減量ΔZ；點選尺寸只顯示相關的PCB、銅塊或錫片，h則顯示容腔，其他零件隱藏。定位視窗不使用呼吸動畫，靜態端點隨選取零件完整入鏡，可自行縮放；2D等比縮放只改幾何，標籤留在視窗內。容腔為藍色、錫料為紅色，所選體積保持不透明並呼吸發光。

## PA 底座／PCB 開窗單邊間隙

分析放在PCB設定末端：

`最小 = (PCB最小尺寸 − PA最大尺寸) / 2`

`最大 = (PCB最大尺寸 − PA最小尺寸) / 2`

預設X為0.0515～0.2785 mm，Y為0.0465～0.2735 mm。PA與PCB開窗固定同心，表格列出Typ.、最小與最大的**尺寸極限**；不能把0.066再當成尺寸公差扣一次。負值會標出可能干涉。PCB與PA隨中凸台共同平移不改變相對間隙。

## 圓角、孔位與真實破邊

先建立E×F、R的圓角基座，再從兩相鄰直邊以C定位孔中心，最後用D圓柱切除。C不必大於R，孔也不必保持完整閉孔；加大到穿破圓角時，預覽、STEP和DXF顯示真正缺口，DXF不會保留假的完整孔圓。完全沒有切到基座、相切與穿破會分別提示。若孔切入凸台或切斷基座，會拒絕無法作為此單一銅塊的結果。

`copper-geometry.js`共用實際布林輪廓；體積以解析圓弧／自適應積分求真正切除面積，沒有直接扣掉已落在基座外的完整圓。共圓弧採同一角度網格，避免相切產生數值薄片。輪廓弦差≤0.0001 mm；真正STEP仍為CAD圓弧。

## 中凸台定位

Xc／Yc分別為基座左邊／下邊至中凸台中心的距離，預設E/2、F/2，可變更或按「置中」。`boss_center=[Xc−E/2,Yc−F/2]`。中凸台、四角小凸台、PA、組裝中的錫片、PCB開窗及Layout陣列一致跟隨；基座及吊掛孔保留基座座標。獨立錫片出圖仍置於自身原點。新增的定位尺寸／公差並非PPT規定，來源會明示。

## Layout 綠漆／E-PAD：第9頁

R＝外框綠漆寬1；S＝E-PAD邊長1.5；T＝綠漆筋0.3（格距S+T）；U＝同PCB開窗；V＝定位孔避讓直徑4，單位mm。陣列中心跟隨開窗，邊緣與圓角裁切。V小於真實孔D時仍扣除真孔並提示，不以綠漆填入孔內。

| DXF圖層 | 意義 |
|---|---|
| SOLDER_MASK | 綠漆覆蓋區 |
| EPAD_OPENING | 裸露E-PAD／綠漆開窗 |
| MASK_BOUNDARY | 含R外框的邊界 |
| COPPER_BOUNDARY | 真實銅塊外形 |
| PCB_CUTOUT | U開窗參考 |
| HOLE_CLEARANCE | V避讓參考 |
| MOUNT_HOLE | 實際孔的參考輪廓 |

SOLDER_MASK與EPAD_OPENING具封閉輪廓及SOLID HATCH，極性明確。V用於排除E-PAD，D到V間保留綠漆環；R依圖解讀為銅塊外側綠漆帶。邊緣落入綠漆筋的餘量寫入報告，仍需與Layout確認。錫量容腔的避空面積Aₒ直接採用PCB第7/9頁四個側向半圓的聯集面積（2πr²，同側重疊時扣除），與Layout輪廓一致；第12頁原式只計一個整圓πr²，已不採用。

## 2D 圖面（銅塊／錫片）：348001J40001 格式

出圖零件選銅塊或錫片後，「2D 圖面 DXF ↓」「2D 圖面 PDF ↓」輸出該零件的圖面；完整出圖包同時包含兩個零件的 DXF 與 PDF。圖面依公司圖面 348001J40001（Creo 轉出的 DXF R2000）的出圖格式產生。圖框、標題欄、DELTA 標誌、箭頭與表面粗糙度符號直接取自原圖；視圖、尺寸、公差、Note 由工具即時繪製。

- **銅塊視圖**：俯視主視圖（含 B-B 剖切線）、上方截面 B-B（剖面線、平面度／平行度框、粗糙度 1.6）、右側細節 A（小凸台 4:1）。尺寸位置、箭頭內外、文字與箭頭的距離沿用原圖；銅塊較大放不下時，主視圖依序改為 1:1、1:2…，並移動位置避開 Note 與標題欄。
- **錫片視圖**（依使用者提供的錫片圖面格式）：俯視圖左側 *X、下方 *W、右上角兩個 45° 削角邊長 *Y（外置箭頭）；右側為側視圖，上方標 *Z（選定試片厚度，取兩位小數），並畫出削角稜線；比例 3:1 標在俯視圖下方，Note 在側視圖下方（材料 96.5Sn3Ag0.5Cu COATED WITH 0.5%F8 FLUX、Delta 規範 10000-0002／0094、10000-0162、"*" 為關鍵尺寸）。尺寸全部標 *；錫片較大放不下時改為 2:1、3:2…。
- **公差**：全部跟隨「公差來源與鎖定」的設定。對稱公差標「±」；不對稱以上下堆疊顯示（例：G 為 0／−0.10、Y 為 +0.20／0）；公差為 0 的尺寸不標公差，由標題欄的一般公差表管轄。
- **料號**：銅塊與錫片各自一組，共 12 碼＝前 10 碼＋REV 2 碼（例：348001J400＋01＝348001J40001，與原圖檔名一致）。前 10 碼填入標題欄 PART NO.，REV（00、01、02…下拉選擇）填入圖面與封面標題欄的 REV.。填滿 10 碼後可上鎖，鎖定狀態隨專案儲存；未填時銅塊顯示 348XXXXXXX、錫片顯示 XXXXXXXXXX。
- **標題欄**：DATE 為出圖當天，USED ON 為專案名稱，描述為 Cu base E*F*總高／Solder preform W*X*Z。原圖的 NET26-2013200A 不帶入。
- **封面**：預設含封面（還原成第一版，只保留「1.發行圖面」00 列）。REV 01 以後封面標題欄顯示新的 REV，修訂紀錄表的修改說明需另行補上。含封面時封面為 SHEET 1 OF 2、圖面為 2 OF 2；取消勾選「含封面」則只有圖面，SHEET 1 OF 1。勾選狀態會記在這台瀏覽器。
- **DXF**：R2000、代碼頁 ANSI_950（Big5），與原圖相同；Big5 以外的字元以 `\U+XXXX` 寫入。
- **PDF**（dxf-pdf.js）：直接由同一份 DXF 文字繪製向量 PDF，封面 A4 直式、圖面 A4 橫式（圖面 1 單位＝1.5 mm）。出圖方式比照使用者以 AutoCAD 從原圖轉出的 PDF（有浮水範例.pdf）：全部黑色、所有線條為髮絲線（線寬 0），DELTA 標誌、圖框與文字粗細與原圖相同。文字依 DXF 字型樣式：字型檔為 arial.ttf 的樣式（標題欄、Note）以 Arial 字寬（Helvetica）繪製；其他樣式（尺寸、中文標籤、封面）比照原圖的微軟正黑體——字級比 0.7566、拉丁字依正黑體字寬逐字排列，中文使用繁中黑體 MHei-Medium；封面料號的 PMingLiU 以 Times／MSung-Light 代替。字型不內嵌，由 Acrobat 與瀏覽器提供。與原圖逐字比對：標題欄與 Note 的字級、位置誤差小於 0.03 pt。pdf-lib 只在第一次輸出 PDF 時載入。
- **浮水印**：勾選「浮水印」後套用「設定 → 浮水印」上傳的 PDF／PNG／JPG。作法比照使用者以 Acrobat 手動加浮水印的範例（有浮水範例.pdf）：取浮水印 PDF 的 ArtBox（圖片為整張）等比縮放到頁面短邊的 80%、置中、不透明度 50%、旋轉 0°，包在透明群組中並放在頁面內容之前繪製，因此位於圖面之下（背景）；與範例逐點比對位置與顏色一致。比例、不透明度、旋轉可在設定中調整。
- **浮水印存放**（watermark-store.js）：檔案與 watermark.json（檔名、大小、SHA-256、時間、外觀）另存於 Watermark 資料夾，不併入專案資料庫 JSON：SharePoint 為 Thermal-Spec-DB／文件／PA_Copper_CAD/Watermark；本機為設定中所選資料夾（建議選資料庫檔所在的資料夾）下的 Watermark。瀏覽器另保留一份副本供離線輸出；重新讀取時採用最新的一份。

## 驗證與原生 PRT

測試涵蓋尺寸／公差來源、間隙上下限、所有欄位尺寸端點、破邊與相切、凸台移位與K高度、全欄位顯示、七視角、彩色色階、公式提示、手機版、真實STEP回讀與DXF獨立稽核。GitHub Actions上線前將32個尺寸分四組平行驗證七視角；所有組都通過才部署。上線後再驗證八個代表尺寸與完整下載流程，保留截圖、下載包與失敗診斷。新修改會取消尚未完成的舊版部署，優先發布最新版本。

原生PRT仍須在已授權的Creo Parametric 7.0.10.0／Windows11與真實參數化母檔上執行。新增BOSS_X/Y位置參數會交給本機任務；質量與外形檢查不能證明位置再生，需實機幾何驗證。網站沒有宣稱生成／驗證原生PRT。

## 可選吊掛孔角位

俯視角位可單選或複選左上、右上、左下、右下（至少一角）；未指定的舊專案維持左下／右上。孔中心依 C 距相鄰外邊，銅塊輪廓、體積、STEP、DXF、D/V標註數量及Layout E-PAD避讓都使用相同選孔資料，PCB不增加這些孔。專案、JSON及原生Creo任務一併保存角位；替代角位需要支援HOLE_MASK的Creo母件，詳見原生特徵契約。

## 自動削角與試片驗證結果

Y = 2J + √2 × 0.2828 mm，維持小凸台到45°斜邊的設計最近距離基準0.2828 mm；因此J=1.5時Y=3.40 mm；取位後實際間隙約0.282843 mm。錫片面積178.760000 mm²、計算Z約0.374779 mm，三款試片為0.224779／0.374779／0.524779 mm。Y四捨五入取兩位，任意J取值造成的實際間隙也列在圖解中。Y和增減量0.15為唯讀，修改J會自動更新削角、面積及試片厚度。

左側圖解按鈕後以重點色塊列出下／中／上三款，選單、候選值與下方選定結果皆四捨五入顯示兩位小數（計算、儲存與模型仍保留完整精度）；從「錫片厚度驗證後選定」選擇；鎖頭將完整精度的厚度、選項、設計簽章及確認時間保存在本機專案。模型、STEP、DXF及Creo任務均使用所選厚度。鎖定後相關幾何若變動，保留原始記錄並標示需重新驗證，在解鎖前阻擋製造出圖。舊的手動Z及試片增減量匯入時改用此流程。

各零件的◐按鈕只切換半透明／實體，與顯示勾選分開；所有零件仍為同一幾何。翻轉等角以X軸180°轉換視角，保持正投影比例。工具列的「格線」按鈕可開關背景格線，切換零件或視角仍保留選擇。
