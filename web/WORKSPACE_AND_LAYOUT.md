# PA 銅塊尺寸工作區與出圖

[線上工具](https://tedus-ai.github.io/pa-solder-copper-auto-draw/) 是自含 HTML／JavaScript；Three.js 預覽、OpenCascade WebAssembly 製造模型與 GitHub Pages 部署。24吋常見1920×900／1080工作區中，設定區約605 px、3D區約佔67%寬；上下區塊等寬卡片、中間銅塊橫跨兩欄並整合基座與凸台，統一尺寸／公差欄；短桌面22 px列高，較高桌面25 px，主要設定不需捲動。指標列38 px，頁首與出圖列縮小以增加畫布。1366×768仍維持左右並排，短畫面只在設定區必要時捲動；錫片／Layout預設展開，也可自行收合；手機使用單欄。

## 彩色 CAD 與標註

銅塊基座、中凸台、四角小凸台分成三種銅色，含實際出圖模型的網格；深色輪廓、棚光反射與接觸陰影讓俯視仍能看清凸台邊界。PA為銅色底座、單一深色封裝本體及六支示意金色針腳，沒有獨立的灰色頂蓋。參考 [anatomy 的明暗／厚度原則](https://github.com/wheresryan22/anatomy/blob/main/SKILL.md)，保留真正的彩色CAD與工程標註。

32個設計尺寸（Typ.）均有對應的實際尺寸端點。點選設計尺寸（Typ.）切換正投影判讀面；六面與等角仍可自由旋轉；選用六面時「正投影」亮起，等角按鈕與其互斥。尺寸文字固定深色，依實際字寬放在模型外側；一般尺寸水平，四角半徑文字沿外側斜引線排列，只有圓弧端點的光圈呼吸。數值統一為 `PA(L) = 20.57 ±0.127 mm` 等工程格式，重複特徵加數量：四角半徑 `4-R = 3.00 mm`、兩孔 `2-⌀D = 3.00 mm`，J/K/Y各4處，O4處、V2處。這些特徵至少顯示兩位小數，仍保留更精細的輸入，例如3.005不會被改成3.00；尾零不代表另行指定製造公差。DXF同樣使用數量、代號／名稱、等號、數值及單位。小間距採外置箭頭。半徑選擇尚未被孔切除的圓弧，採就近的外側斜直線及單箭頭，不再畫穿過本體的圓心線；直徑使用實際直徑線與兩軸點劃中心線。

聚焦PA長／寬的公差欄時，只顯示最大外框虛線及外側公差文字，不另畫 ± 微小線段。SPH下端是PA金屬底座底面，上端是PIN底面，側視基準與示意模型一致。上方尺寸列獨立於模型區；極端放大無空白時保留尺寸列，可按「定位視角」還原。

銅塊、錫片、PCB、PA、E-PAD設計皆可獨立切換；隱藏或分解不影響製造圖檔。PCB為只有PA開窗／角部避空的局部板，不複製銅塊的兩個吊掛孔；這兩孔仍保留於銅塊及Layout設計。E-PAD切換控制參考組裝／Layout的綠漆與開窗示意，不加入3D製造輸出。PA自身形狀及針腳為示意。STEP／STL只有銅塊與錫片。


## 專案與 PA 型號

專案名稱與PA型號並排，支援中文及單行文字；專案名稱必填，PA型號可留空。Typ.表示未加上下公差的設計尺寸，不是實測平均值。銅塊基座、中凸台、四角小凸台整合於同一銅塊設定區；L標示為「中凸台總高L」。

專案目前存於這個瀏覽器的localStorage，保存完整尺寸、公差、專案名稱與PA型號，支援重新載入、更新、另存與刪除；尚未連接後端，清除瀏覽器資料會移除本機儲存。儲存介面集中於project-store.js，供未來替換成後端服務。CAD檔名代碼design.name與人可讀的project.name／project.pa_model分開，保持原生Creo檔名規則與舊參數檔相容。

## 公差來源與鎖定

每個尺寸旁有正、負偏差，輸入非負量。預設鎖定，按「解鎖公差」可修改。來源標記可查看文件頁碼；原文件沒有公差的欄位顯示「—／未指定」，分析暫按0，而非宣稱製造公差為零。手動值會標示來源變更。

| 尺寸 | 原文件公差 | 來源 |
|---|---|---|
| PA長、寬 | ±0.127 | 第8頁明載上限 +0.127；下偏差沿用雙向公差設定，可解鎖修改 |
| 基座E/F | ±0.2 | 第3頁 |
| 基座G | +0/−0.1 | 第3頁 |
| 孔中心距邊C | ±0.1 | 第3頁 |
| 中凸台I/H | ±0.05 | 第4頁 |
| 中凸台總高L | +0/−0.1 | 第4頁 |
| 四角小凸台J/K | ±0.05 | 第4頁 |
| PCB開窗M/N | ±0.1 | 第7頁 |
| 錫片W/X | ±0.1 | 第11頁 |
| 錫片削角Y | +0.2/−0 | 第11頁 |
| 錫片厚度Z | ±0.02 | 第11頁 |

SPH、PCB板厚、A/B/D間距、基座圓角R、孔徑D/O、Layout R/S/T/V及新增凸台位置公差均未指定。HSK（散熱器）須在銅塊的相對位置加工凹槽，槽深設計值為銅塊基座厚度G+0.05 mm；HSK槽深加工公差±0.05 mm，見第3頁。G=3 mm時，槽深設計值3.05 mm，允許深度3.00～3.10 mm。試片增減量±0.05（第12頁）／±0.15（第13頁）的差異與Z製造公差±0.02分開揭露。

公差存在 `design.tolerances['group.field'] = {minus,plus}`。PA長寬／PCB開窗可有不同公差。舊檔的 `package.max_tolerance`、`pcb.opening_tolerance`會轉入新欄位；舊檔含M/N但無模式時保留手動開窗。

## 自動計算與圈圈問號

自動值旁的圈圈「?」可用滑鼠移入、鍵盤聚焦或手機點選，查看公式、目前代入值與結果。涵蓋M/N、I/H、L、W/X、PA最大尺寸、HSK深度、凸台下段高、錫厚／體積／面積、試片及間隙極值。手動模式的對應自動提示會隱藏；浮動說明不被尺寸面板裁切。

- I/H：PA標稱長寬向上取到0.1 mm；預設自動，取消跟隨可修改設計長寬（Typ.）。
- L：依**第6頁** `L = PCB厚度C + A + B − SPH − D + K`，固定自動計算，不能手填覆寫。A/B/D使用0.1／0.1／0.3 mm建議定值，SPH從PA帶入，高度區可調PCB厚度C與小凸台K。
- 中凸台本體高度＝L−K；四角J×J小凸台再向上拉K，所以總高仍是L，沒有把K重複加兩次。
- W/X跟隨I/H設計尺寸（Typ.），但錫片±0.1的公差與銅塊±0.05各自獨立。
- M/N：最大PA＋固定製程能力0.066＋PCB各軸下偏差（Delta）；Ampleon最後一項除2，再向上取0.1 mm。下偏差用來補償開窗加工縮小，對稱公差時與原PPT相同。0.066不再提供獨立可填欄位，也不作為尺寸公差。

## 錫厚圖解與 Excel 對照

點選上方錫厚／錫量的問號，或頁首「錫厚圖解／計算表」，可開啟以目前尺寸代入的圖解。剖面可切換容腔V₁₋₁、銅凸台V₂及錫料V₁；錫片俯視圖顯示四角削角，並逐步列出h=L+D−K、V₁=V₁₋₁−V₂、A₁=W×X−2Y²及Z=V₁/A₁。剖面高度放大供判讀，並非加工比例。

Excel對照頁保留PDF第13頁範例欄，旁列目前專案數值和公式；計算Z與手動指定的模型Z分開說明。第12頁增減量0.05 mm與第13頁範例0.15 mm同時揭露；仍由左側試片增減量選定，不與Z的製造公差混用。

## PA 底座／PCB 開窗單邊間隙

分析放在PCB設定末端：

`最小 = (PCB最小尺寸 − PA最大尺寸) / 2`

`最大 = (PCB最大尺寸 − PA最小尺寸) / 2`

預設X為0.0515～0.2785 mm，Y為0.0465～0.2735 mm。PA與PCB開窗固定同心，表格列出Typ.、最小與最大的**尺寸極限**；不能把0.066再當成尺寸公差扣一次。負值會標出可能干涉。PCB與PA隨中凸台共同平移不改變相對間隙。

## 圓角、孔位與真實破邊

先建立E×F、R的圓角基座，再從兩相鄰直邊以C定位孔中心，最後用D圓柱切除。C不必大於R，孔也不必保持完整閉孔；加大到穿破圓角時，預覽、STEP和DXF顯示真正缺口，DXF不會保留假的完整孔圓。完全沒有切到基座、相切與穿破會分別提示。若孔切入凸台或切斷基座，會拒絕無法作為此單一銅塊的結果。

`copper-geometry.js`共用實際布林輪廓；體積以解析圓弧／自適應積分求真正切除面積，沒有直接扣掉已落在基座外的完整圓。共圓弧採同一角度網格，避免相切產生數值薄片。輪廓弦差≤0.0001 mm；真正STEP仍為CAD圓弧。

## 中凸台定位

Xc／Yc分別為基座左邊／下邊至中凸台中心的距離，預設E/2、F/2，可變更或按「置中」。`boss_center=[Xc−E/2,Yc−F/2]`。中凸台、四角小凸台、PA、組裝中的錫片、PCB開窗及Layout陣列一致跟隨；基座及吊掛孔保留基座座標。獨立錫片出圖仍置於自身原點。新增的定位尺寸／公差並非PPT規定，來源會明示。

## Layout 綠漆／E-PAD：第9頁

R＝外框綠漆寬1；S＝E-PAD邊長1.5；T＝綠漆筋0.3（格距S+T）；U＝同PCB開窗；V＝定位孔避讓直徑4，單位mm。陣列中心跟隨開窗，邊緣與圓角裁切。V小於真實孔D時仍扣除真孔並提示，不以綠漆填入孔內。

| DXF圖層 | 意義 |
|---|---|
| SOLDER_MASK | 綠漆覆蓋區 |
| EPAD_OPENING | 裸露E-PAD／綠漆開窗 |
| MASK_BOUNDARY | 含R外框的邊界 |
| COPPER_BOUNDARY | 真實銅塊外形 |
| PCB_CUTOUT | U開窗參考 |
| HOLE_CLEARANCE | V避讓參考 |
| MOUNT_HOLE | 實際孔的參考輪廓 |

SOLDER_MASK與EPAD_OPENING具封閉輪廓及SOLID HATCH，極性明確。V用於排除E-PAD，D到V間保留綠漆環；R依圖解讀為銅塊外側綠漆帶。邊緣落入綠漆筋的餘量寫入報告，仍需與Layout確認。PCB第7/9頁四個側向半圓與第12頁錫量公式的等效πr²面積分開保留，未互相取代。

## 驗證與原生 PRT

測試涵蓋尺寸／公差來源、間隙上下限、所有欄位尺寸端點、破邊與相切、凸台移位與K高度、全欄位顯示、七視角、彩色色階、公式提示、手機版、真實STEP回讀與DXF獨立稽核。GitHub Actions上線前將32個尺寸分四組平行驗證七視角；所有組都通過才部署。上線後再驗證八個代表尺寸與完整下載流程，保留截圖、下載包與失敗診斷。新修改會取消尚未完成的舊版部署，優先發布最新版本。

原生PRT仍須在已授權的Creo Parametric 7.0.10.0／Windows11與真實參數化母檔上執行。新增BOSS_X/Y位置參數會交給本機任務；質量與外形檢查不能證明位置再生，需實機幾何驗證。網站沒有宣稱生成／驗證原生PRT。
